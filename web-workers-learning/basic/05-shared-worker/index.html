05: SharedWorker

学習ポイント:
・SharedWorker は複数のタブ/ウィンドウで1つの Worker を共有する
・通信は MessagePort 経由（worker.port）
・onconnect で新しい接続を処理（Dedicated Worker にはない）
・このページを複数のタブで開いてチャットしてみてください！ 
// Dedicated Worker との違い
const dedicated = new Worker("worker.js");
dedicated.postMessage(data);      // 直接通信

const shared = new SharedWorker("shared-worker.js");
shared.port.postMessage(data);    // port 経由で通信
shared.port.start();              // 明示的に開始が必要
