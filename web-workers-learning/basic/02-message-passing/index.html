学習ポイント:
・id を使って Request/Response を紐付ける
・ストリーミング: Worker から複数回 postMessage して進捗を送信
・構造化データ（オブジェクト・配列）はシリアライズされてコピーされる
・structured clone algorithm により、ほとんどの JS オブジェクトを送れる
