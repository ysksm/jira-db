04: Transferable Objects

学習ポイント:
・通常の postMessage はデータを構造化クローンでコピーする
・Transferable Objects は所有権を移転し、ゼロコピーで高速
・transfer 後、元のスレッドからはバッファにアクセスできなくなる
・対象: ArrayBuffer, MessagePort, OffscreenCanvas など 
// 構造化クローン（コピー）
worker.postMessage({ buffer: arrayBuffer });

// Transfer（ゼロコピー、所有権移転）
worker.postMessage({ buffer: arrayBuffer }, [arrayBuffer]);
