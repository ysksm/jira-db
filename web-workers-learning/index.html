Web Workers Learning

Web Worker は JavaScript をメインスレッドとは別のバックグラウンドスレッドで実行する仕組みです。
重い計算や高頻度処理をオフロードすることで、UIの応答性を維持できます。

基本編はバニラ JS で直接ファイルを開いて学べます。
応用編は React + TypeScript で構築されており、cd advanced/react-workers && npm run dev で起動します。

基本編 (Vanilla JavaScript)

基本 01: 基本的な Web Worker

postMessage / onmessage によるメッセージング、UIブロッキングの回避

基本 02: メッセージパッシングパターン

Request/Response、ストリーミング、構造化データの送受信

基本 03: エラーハンドリング

onerror、try/catch、terminate()、Worker の再作成

基本 04: Transferable Objects

ゼロコピー転送、ArrayBuffer、パフォーマンス比較、画像処理

基本 05: SharedWorker

複数タブでの Worker 共有、MessagePort、タブ間チャット

応用編 (React + TypeScript)

起動方法: cd advanced/react-workers && npm run dev

応用 06: React + Worker 基本統合

Vite での Worker インポート、useRef / useEffect でのライフサイクル管理

応用 07: useWorker カスタムフック

汎用 Worker フック、Promise ベースの通信、Promise.all で並列実行

応用 08: Worker + useReducer

Reducer ロジックを Worker にオフロード、状態管理との統合

応用 09: 高頻度ポーリング Dashboard

Worker による高頻度ポーリング、リアルタイムチャート、異常検知
