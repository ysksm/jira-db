Snapshot Generation Algorithm
generate_snapshots.rs → generate_snapshots_for_issue() L562-780

変更履歴からのポイントインタイム復元

Phase 1: 逆方向適用

現在のデータに全変更を逆順に適用して初期状態を復元

current_state = issue.raw_json for change in history.reverse(): field[change.field] = change.from
L589-601
→
Phase 2: Version 1 作成

復元した初期状態からVersion 1スナップショットを生成

snapshot_v1 = { valid_from: created_date, valid_to: first_change_time, updated_date: created_date, raw_data: None // 最新のみ保持 }
L604-667
→
Phase 3: 順方向適用

各変更を順に適用してVersion 2〜Nを生成

for i, change in history: apply_change(state, change) snapshot_vN = { valid_from: change.time, valid_to: next_change.time, updated_date: change.time, raw_data: if last { json } else { None } }
L670-777
raw_data は最新バージョン (valid_to=NULL) のみ保持。中間バージョンでは labels, components, fix_versions のみ raw_data から抽出後に破棄 (メモリ最適化)。
